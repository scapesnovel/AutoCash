# L32 Website Factory: 100 Tools for Agentic Workflows

This directory contains the flagship L32 Website Factory, a collection of 100 specialized micro-tools designed to accelerate agentic workflow configuration, debugging, and benchmarking. 

## Core Capabilities:
- **Configuration Generation:** Tools for Laya, Browser-Use, ZCode, MCP, and Praxist.
- **Debugging & Profiling:** Latency profilers, event log debuggers, and schema validators.
- **Agentic Infrastructure:** RAG pipeline configurators, system prompt builders, and workflow visualizers.

## Status:

- **Accessibility:** Centralized index at `index.html`.
