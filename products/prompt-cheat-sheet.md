# Prompt Engineering Cheat Sheet

## Core Principles
- **Role:** Define the AI's persona.
- **Context:** Provide background info.
- **Task:** Be specific about the output.
- **Constraints:** Define what to avoid.
- **Format:** Specify the desired structure (e.g., table, JSON, bullet points).

## Example Template
'Act as a [ROLE]. Your task is to [TASK]. Consider [CONTEXT]. The output should be [FORMAT]. Avoid [CONSTRAINTS].'

## Pro-Tips
- Use 'few-shot' prompting: provide 2-3 examples.
- Chain of Thought: ask the AI to 'think step-by-step'.
