# Prompt Engineering Cheat Sheet

## Core Principles
- **Role Prompting**: Assign a persona (e.g., 'You are a senior software architect').
- **Chain of Thought**: Ask the model to 'think step-by-step'.
- **Few-Shot Prompting**: Provide 2-3 examples before asking for the output.

## Advanced Techniques
- **Delimiters**: Use triple quotes or XML tags to separate instructions from input data.
- **Constraint Setting**: Explicitly list what the model should NOT do.
- **Output Formatting**: Request JSON, Markdown, or specific table structures.

## Developer Workflow
- Use these prompts for generating documentation, unit tests, and refactoring code.
